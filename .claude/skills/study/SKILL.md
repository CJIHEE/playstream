# /study <주제 또는 Phase 번호>

1. 인자가 없으면 `docs/ROADMAP.md`에서 체크되지 않은 첫 단계를 현재 단계로 본다.
2. `de-tutor` 에이전트에게 학습 가이드를 요청한다. 현재 단계, 주제, 이미 머지된 코드 경로를 함께 전달한다.
3. 결과를 아래 형식의 **학습 카드**로 사용자에게 보여준다.

```
## 학습 카드: <주제>
- 왜 지금 배우나: 이번 단계에서 이 개념이 쓰이는 곳
- 볼 자료: 강의자료 챕터 / 실습 레포 경로 / 블로그 (예상 학습 시간)
- 핵심 개념 3개: 각 한 줄 정의
- 스스로 답할 질문 5개 (면접 꼬리질문 스타일)
```

4. 사용자가 공부를 마치고 질문에 자기 말로 답하면, de-tutor 관점에서 피드백한다 (맞은 부분, 빠진 부분, 틀린 부분).
5. 사용자가 원하면 `docs/study/<NN>-<주제>.md`에 학습 카드, 사용자의 답변, 피드백을 저장한다. 저장 전에 내용을 보여주고 승인받는다.
